**ДОКУМЕНТАЦИЯ К УРОКУ №10 "Создание отчетов в Allure Report"**
## Описание базового синтаксиса записи и форматирования
   Проект использует следующие технологии и синтаксис:
1. **Python**: Основной язык программирования для написания тестов.
2. **Selenium**: Библиотека для автоматизации взаимодействия с веб-браузером.
3. **Pytest**: Фреймворк для написания и запуска тестов.
4. **Allure**: Инструмент для генерации отчетов о выполнении тестов.

### Форматирование кода
- Код форматируется в соответствии с UTF 8 (стиль написания кода на Python).
- Используются docstrings для документирования методов и функций.
- Все шаги теста размечаются с помощью '@allure.step' или 'with allure.step' для улучшения читаемости отчетов.

## Инструкция по запуску тестов для формирования отчета Allure в Windows
1. Перейдите в папку с тестами: cd <путь к папке>
2. Установите необходимые зависимости:
   '''
   pip install requirements.txt -r
   или в универсальном формате
   python -m pip install -r requirements.txt
   '''
3. Проверьте наличие файла run_allure.ps1 в папке lesson_10
4. Запустите тесты командой .\run_allure.ps1
     Эта команда запустит все тесты в папке lesson_10, сохранит результаты в директорию \allure-results
        и автоматически откроет отчет в браузере.
    В автоматически созданной папке \final-report запишется история прогонов тестов.
5. В отчете Allure вы увидите:
   - **Название теста**
   - **Описание теста**
   - **Шаги теста**:
   - **Результат**: Успешное выполнение или ошибка с указанием ожидаемого и фактического результата
